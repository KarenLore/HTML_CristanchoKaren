## Sección 1: Tarjeta
### Descripción:
Este proyecto presenta una página web que utiliza un formato de tarjeta para mostrar información de manera estructurada y visualmente atractiva. Ideal para presentar datos de contacto, productos o cualquier otro contenido que se beneficie de un diseño en tarjetas.

## Sección 2: Barra
### Descripción:
En este proyecto, se ha diseñado una página web con una barra de navegación destacada. La barra incluye enlaces interactivos que permiten una navegación fluida entre diferentes secciones de la página. Es útil para sitios web que requieren una estructura de navegación clara y accesible.

## Sección 3: Dino
### Descripción:
Inspirado en el icónico juego del dinosaurio de Google Chrome, este proyecto ofrece una experiencia lúdica en una página web. Se enfoca en la recreación de la jugabilidad y el estilo visual del juego, proporcionando una experiencia entretenida para los visitantes.

## Sección 4: Call Of Duty
### Descripción:
Este proyecto está relacionado con el popular videojuego Call of Duty. La página incluye elementos gráficos y de diseño que capturan la esencia del juego, ofreciendo a los fans una interfaz que complementa la temática del videojuego.

## Sección 5: I.Solidario
### Descripción:
Esta página está diseñada para proporcionar información sobre el programa Ingreso Solidario en Colombia. Incluye un formulario para que los usuarios consulten el estado de su beneficio, así como secciones detalladas sobre las etapas de entrega y respuestas a preguntas frecuentes. Es una herramienta valiosa para los beneficiarios del programa que buscan información actualizada y detallada.
